# RCyber Freelancer — Portfolio

Portfolio professionnel statique, bilingue français/anglais, conçu pour être hébergé gratuitement avec GitHub Pages.

## Contenu
- `index.html` : structure et contenu du site
- `styles.css` : identité visuelle responsive
- `script.js` : menu mobile, changement de langue et année dynamique

## Personnalisation avant publication
1. Remplacer l'adresse e-mail de démonstration `contact@rcyber.example` dans `index.html`.
2. Vérifier chaque description de projet et ne conserver que les compétences et réalisations que vous pouvez démontrer.
3. Ajouter des captures d'écran réelles et des liens de démonstration lorsque les projets sont prêts.
4. Ajuster les textes de disponibilité et les services selon les missions réellement proposées.

## Publication GitHub Pages
1. Envoyer les fichiers à la racine du dépôt `RollandMami.github.io`, sur la branche `main`.
2. Dans GitHub : **Settings → Pages**.
3. Sous **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner `main` et `/ (root)`, puis enregistrer.
5. Le site sera publié sur `https://rollandmami.github.io/` après quelques minutes.

Aucun framework ni compilation n'est nécessaire.
